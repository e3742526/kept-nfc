# SheepKeep security policy

Use GitHub's private vulnerability reporting for SheepKeep if the repository offers it. Include
the version or revision from `/version`, the affected component, and the conditions required to
reproduce it. Keep vulnerability details out of public reports.

GitHub private reporting is currently disabled on the fork.

For an issue in upstream Kept, see the [Kept security policy](https://github.com/keptinventory/kept/security/policy).
Test with an instance you operate.
